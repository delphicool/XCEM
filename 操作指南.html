一、系统简介

1.1 系统是什么

本系统是专为无人机足球赛事设计的单机版赛事管理工具，覆盖从"创建组别 → 报名 → 抽签 → 场地编排 → 资格赛 → 排名晋级 → 淘汰赛 → 决赛"的完整赛事流程，并支持场地大屏展示、报表导出与全程操作日志审计。

系统为一个单文件网页应用（xcct_v6.html），无需安装、无需联网、无需服务器。双击用浏览器打开即可使用。

1.2 运行环境与数据保存

  • 推荐浏览器：Chrome 或 Edge（支持 xlsx 文件解析等新特性）。
  • 所有数据自动保存在本机浏览器（localStorage）中，关闭页面不丢失。
  • ⚠️ 数据绑定当前浏览器：换电脑、换浏览器、清除浏览器数据都会丢失数据。请务必在"赛事设置"页定期导出 JSON 备份。

1.3 赛事规则速览（系统内置）

环节规则
资格赛环形对阵，每队 2 场（BO1）；按抽签顺序相邻对阵（a vs a+1，最后一队回头打第一队）
排名（8 级）① 总积分 ② 净胜球 ③ 总进球 ④ 相互比赛积分 ⑤ 相互比赛净胜球 ⑥ 相互比赛进球 ⑦ 总失球（低） ⑧ 抽签号升序破同分
积分胜 3 分 / 平 1 分 / 负 0 分（可在赛事设置中修改）
晋级淘汰规模 N 强；特邀名额 M 自动释放：前 R0=N−M 名排名晋级，特邀队伍已自然晋级的顺延释放名额
淘汰赛对阵种子 1 vs N、2 vs N−1……（16强赛 → 8强赛 → 4强赛 → 季军赛 + 冠亚军决赛）
决赛赛制BO1 / BO3 / BO5 可选（默认 BO1）；BO3/BO5 系列红蓝方不互换
比分范围 0–999；支持金球胜、死亡点球胜、弃权判负（默认 0:9）
场次编号资格赛按场地全局连续编号；淘汰赛每个阶段每个场地均从第 1 场开始编号

二、快速上手：一场赛事的完整流程

按以下 12 步即可完成一场完整赛事：

1
赛事设置：填写赛事名称、地点、日期；确认场地数量、积分规则、决赛赛制；修改操作密码（默认 admin123）。
2
组别管理：创建组别（如小学组/中学组/大学组），设置资格赛场次、淘汰规模（4/8/16/32/64 强）、特邀名额、决赛赛制。
3
队伍管理：录入或批量导入各队（队名、单位、是否特邀），点"自动分配抽签号"，点"校验本组"确认数量合规。
4
抽签：点"全部组别校验"确认全部通过 → 导出抽签报名模板（xlsx）→ 现场抽签填号 → 导入抽签报名模板或粘贴抽签结果 → 系统自动生成资格赛赛程。
5
场地编排：点"一键推荐"自动分配队伍到各场地 → 点"应用并排程"生成比赛并完成排程。
6
场地排程：按场地 / 按组别查看排程，打印或导出排程表分发。
7
资格赛：现场按排程比赛，在"比赛录入"页录入比分并"确认锁定"。
8
排名：查看实时排名；若有并列，在"破同分录入"区调整抽签号。
9
晋级：确认晋级名单，选择淘汰赛场地 → 点"生成淘汰赛对阵"。
10
淘汰赛：在对阵树中逐场录入；每轮完成后点"生成下一轮"；决赛前可"安排场地场次"。
11
赛事大屏：投屏展示资格赛实时排名 / 淘汰赛对阵树；自动轮播各组别。
12
报表：下载排名表、晋级队伍表、对阵表、检录表、排程表等 6 类报表存档。

四、各页面操作详解

4.1 仪表盘 📊

  • 统计卡片：参赛队伍 / 总比赛数 / 未完结 / 已锁定。
  • 组别进度：每组队伍数、抽签、资格赛进度、淘汰赛进度一目了然。
  • 系统操作：快速跳转"赛事设置""创建组别"；⚠️ 重置赛事数据 清空全部数据（需输入操作密码，与锁屏密码一致）。
重置赛事数据 = 清空全部队伍、抽签、比赛、日志，不可恢复！执行前请先导出 JSON 备份。

最小休息间隔同一队伍相邻两场至少间隔的场次数1

导入 / 导出（备份）

  • 📥 导出 JSON 备份：下载全部数据为 JSON 文件，建议每天赛程结束后备份一次。
  • 📤 从 JSON 恢复：选择备份文件整体恢复（覆盖当前数据）。

4.3 组别管理 🗂️

  • 新增组别：组别名称（小学组/中学组/大学组或自定义）、启用开关、资格赛每队场次（1 或 2 场）、淘汰规模（不创建/4/8/16/32/64 强）、特邀名额、决赛赛制（BO1/BO3/BO5）。
  • 约束：特邀名额 ≤ 淘汰规模；特邀名额 + 淘汰规模 = 最终晋级总数。
  • 编辑 / 删除：删除组别会连带删除其队伍与比赛（有确认提示）。

4.4 队伍管理 👥

添加队伍

选择组别 → 填写队伍名称、所属单位（学校/俱乐部，可选）、是否特邀 → 点"添加队伍"。

批量导入

每行一支队伍，逗号或 Tab 分隔：队伍名,所属单位,是否特邀（特邀列填 y/特邀/是）。

其他按钮

按钮作用
🔢 自动分配抽签号按名称排序自动编号 1..N（抽签前使用）
🌱 生成示例数据快速添加 16 支示例队（4 支特邀）用于演练
✅ 校验本组检查队伍总数、特邀数量是否满足淘汰规模要求；未通过会给出具体原因

队伍列表支持编辑（名称/单位/特邀/备注）、一键切换特邀身份、删除（已有参赛记录的队伍无法删除）。

4.5 抽签 🎲

抽签采用现场抽签结果导入模式：现场用纸条/软件抽签后，把抽签号填回系统。

推荐流程（xlsx 闭环）

  1. 点 🔍 全部组别校验：所有组必须校验通过（队数、特邀名额合规），否则抽签功能被禁用；
  2. 点 📤 导出抽签报名模板：下载该组 xlsx 模板（列：抽签号|队名|单位|组别|特邀）；
  3. 用 Excel 打开模板，现场抽签后在抽签号列填 1..N（不重不漏）；
  4. 点 📥 导入抽签报名模板 选择该文件 → 系统自动解析并预填确认弹窗；
  5. 在弹窗中核对内容，填写抽签人姓名（必填）、备注，点"✅ 校验并导入"。

备选方式：现场粘贴

点 📥 导入抽签结果（现场粘贴），在弹窗文本框粘贴竖线分隔文本：抽签号|队名|单位|组别|特邀（弹窗内有"复制模板"按钮可先复制再改）。

导入成功后自动生成资格赛赛程，并记录到操作日志（含抽签人姓名）。再次导入会覆盖旧抽签结果并重新生成资格赛。

4.6 场地编排 🧩

将各组的队伍（按抽签号段）分配到各场地，段内按"a vs a+1 → … → 末 vs 首"首尾循环生成对阵。每队全程在同一场地比赛，不跨场地。

一键推荐（V2.0 算法）

  • 小组完整放入最空场地；大组按最少段数拆分；每段先补到均载、剩余按负载最小逐 1 分配；一个场地可容纳多个组别的段。
  • 超载容差 delta 可留空自动（默认 max(5, 均载×10%)）。

手动调整

每个场地卡片可手动"添加段"（组别 + 起始抽签号 + 结束抽签号），也可删除段。段之间不可重叠。

应用

  • 📋 应用并排程：按编排重建资格赛赛程并完成排程（T+N 时间槽 + 最小休息间隔）。
  • 🧹 清空编排：仅清空方案，不删已生成的比赛。
  • 📤 导出编排表：xlsx。
已有确认成绩的资格赛时无法重建赛程，需先取消相关比赛的确认。

4.7 场地排程 🏟️（只读双视图）

  • 按场地查看：下拉选场地，列出该场地第 1..N 场（每场红蓝两行：学校、队伍名、组别）；可导出"本场地编排表"xlsx。
  • 按组别查看：每队显示其全部比赛"X 号场地 第 N 场"；可导出"组别排程表"xlsx。
  • 排程由"场地编排"页生成，如需调整请回场地编排页修改后重新应用。

4.8 资格赛 ⚽

  • 选择组别（或全部组别）查看资格赛列表：#、场地、场次、红蓝队、比分、结果、状态。
  • 行内 录入 直接跳转比赛录入页；改 解锁修改已锁定比赛（需填写原因）；× 取消比赛（需填写原因）。
  • 顶部统计：总场数 / 已排程 / 已锁定 / 已取消。

4.9 比赛录入 📝

选择比赛

  • 通过组别下拉 + 阶段下拉缩小范围；阶段包括：资格赛 / 16强赛 / 8强赛 / 4强赛 / 季军赛 / 冠亚军决赛。
  • 搜索框支持模糊搜索：输入场地名称、场次、队名、校名、阶段关键词，逐字符过滤；↑↓ 选择、回车 确认、Esc 关闭。
  • 顶部黄色横条提示"有未确认的比分"时可一键确认。

录入比分

操作说明
分数输入红/蓝队分数 0–999，修改后自动保存（待确认状态）
🚩 红/蓝队弃权该队按弃权判负（默认 0:9），对手胜
⚡ 标记 3 分钟金球胜者选择金球获胜方
⚽ 记录死亡点球胜者选择点球获胜方
✅ 确认结果并锁定比分生效并锁定；淘汰赛自动判定胜者并填入下一轮对阵
🔓 解锁并修改已锁定的比赛可解锁修改，必须填写修改原因，修改前后值记入操作日志；修改比分后系统按新比分自动重算结果，排名与晋级同步更新
× 取消比赛标记比赛为已取消（需填写原因）
BO3/BO5 决赛：确认一场后自动生成系列下一场；红蓝方整个系列不互换；率先取得 2 胜（BO3）/ 3 胜（BO5）即结束系列，多余场次自动取消。

4.10 排名 📈

  • 实时按 8 级规则计算排名，显示场次/胜/平/负/进球/失球/净胜/积分。
  • 破同分：8 级规则仍并列的队伍，页面出现"破同分录入"区，为并列队伍输入互不相同的抽签号（升序定名次），保存后排名立即更新。
  • 📊 保存为 Excel(.xlsx) 导出排名表；🏆 进入晋级设置 跳转晋级页。

4.11 晋级 🏆

  • 显示淘汰规模 N、特邀名额 M、原始排名晋级 R0、已自然晋级的特邀 K，以及最终名单（种子位/队伍/排名/晋级方式）。
  • 特邀释放：特邀队已自然晋级的，名额顺延给后续排名队伍（系统自动计算）。
  • 📸 保存晋级快照 存档当前名单。
  • 生成淘汰赛对阵：先选择淘汰赛场地（默认 1 号场地）→ 点 🏆 生成淘汰赛对阵。对阵按 1vsN、2vs(N−1)；旧版本自动归档不丢失，可随时回看。

4.12 淘汰赛 🪜

对阵树

从左到右：16强赛 → 8强赛 → 4强赛 → 决赛列（冠亚军决赛在上、季军赛在下）。卡片点击即跳转录入该场；确认后胜者自动推进到下一轮。

4.15 操作日志 📜

  • 记录所有重要操作：组别/队伍增删改、抽签导入（含抽签人）、比赛确认与修改（含修改前/后值与原因）、赛事设置、密码修改等。
  • 列表列：时间 / 类型 / 组别 / 对象 / 原因 / 详情。组别与对象自动翻译为名称（如"小学组""16强赛 · 红队 vs 蓝队（1号场地 第3场）"）；已删除的对象显示"（已删除）原始ID"。
  • 点 详情 查看：完整时间、类型、组别、对象、原因、备注、附加信息（操作员/随机种子等）及修改前后对比（只列发生变化的字段）。
  • 📥 导出日志 CSV 存档（含备注列）。

4.16 自检测试 🧪

内置 80 个边界场景测试（排名算法、对阵生成、排程负载均衡、BO3 系列、状态机等）。

运行自检会产生虚拟测试数据，仅用于演练环境。运行前建议先导出备份；测试结束后数据自动恢复。

五、数据备份与安全

5.1 备份策略（强烈建议）

  1. 每半天（午休、晚场结束）在"赛事设置 → 导入/导出"点"导出 JSON 备份"，文件命名加日期。
  2. 重大节点前（抽签导入、生成淘汰赛对阵、重置数据前）先备份。
  3. 备份文件保存在 U 盘或网盘，避免与赛电脑同机单份。

5.2 安全机制

机制说明
操作密码用于锁屏解锁 + 重置赛事数据等高风险操作；默认 admin123，首次使用必须修改；密码以哈希存储不落明文
锁定系统顶栏一键锁定屏幕，需密码解锁；支持自动锁屏（分钟）
已锁定比赛保护已确认的比赛不能直接改分，必须"解锁并修改"且填写原因，前后值记日志
删除保护有参赛记录的队伍不能删除；重置数据需密码；淘汰赛旧版本作废后仍保留可查
操作日志全操作留痕，页面不可直接删除日志，是数据追溯依据

六、常见问题与注意事项

6.1 常见问题

问题处理
抽签页导入按钮是灰色的本组校验未通过（队数/特邀名额不合规）。点"全部组别校验"查看原因，回队伍管理或组别管理调整
录入页找不到某场比赛检查组别/阶段下拉是否过滤了；或用搜索框输入场地、场次、队名关键词
生成的资格赛和预期不一样资格赛由"抽签导入"自动生成、由"场地编排→应用并排程"重建；已有确认成绩时不能重建，需先取消确认
抽签结果填错了想重来直接重新导入抽签结果即可覆盖（自动重建资格赛；如有已确认比赛需先取消确认）
淘汰赛对阵生成错了到"晋级"页重新"生成淘汰赛对阵"会创建新版本，旧版本自动归档、成绩不丢；也可"作废当前版本"
想修改已锁定的比分录入页点"解锁并修改"，填写原因后修改，修改前/后值会记入操作日志；修改后排名与晋级按新比分自动重算
大屏全屏后无法退出按 Esc 键退出全屏
重置数据需要什么密码操作密码（与锁屏密码一致），默认 admin123
换电脑后数据不见了数据存在原电脑浏览器中。请用"导出 JSON 备份"→ 新电脑"从 JSON 恢复"
报表里的场次编号与页面不一致淘汰赛场次按"阶段·场地"局部从 1 编号（打印报表与页面已保持一致）；资格赛按场地全局连续编号

6.2 注意事项

  • 抽签号必须从 1 开始不重不漏，系统会严格校验。
  • 特邀队伍须在队伍管理中勾选"特邀"，否则特邀名额算法不生效。
  • BO3/BO5 决赛系列中不要手动互换红蓝方。
  • 场地数量在赛事设置中修改后，会影响后续编排与排程。
  • 操作日志列表较大时，用导出 CSV 存档。
