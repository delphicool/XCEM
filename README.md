# 星驰赛事管理系统（XCEM）· 无人机足球赛事管理系统

> 单机本地版 · v1.0 · 适用于资格赛 + 淘汰赛制的无人机足球（空中足球）赛事

**XCEM（星驰赛事管理系统，Xingchi Event Management）** 是一款运行在浏览器中的无人机足球赛事成绩管理系统。它覆盖从建组、报名、抽签、场地编排、排程、资格赛成绩录入、8 级排名、晋级计算、淘汰赛对阵、决赛系列（BO1/BO3/BO5）到报表导出、赛事大屏展示与操作日志追溯的完整赛事流程。

## ✨ 功能特性

- **完整赛事流程**：组别管理 → 队伍管理（批量导入/自动编号）→ 抽签（模板导入/现场粘贴）→ 场地编排（一键推荐+负载均衡）→ 场地排程（T+N 时间槽）→ 资格赛（环形对阵，每队 2 场）→ 排名（8 级破同分规则）→ 晋级（特邀名额自动释放算法）→ 淘汰赛（种子对阵 1vsN，胜者自动推进）→ 决赛（BO1/BO3/BO5 系列，红蓝不互换）
- **规则引擎**：胜 3 / 平 1 / 负 0 积分制；弃权判负（默认 0:9）；金球胜、死亡点球胜；比分范围 0–999
- **场地编排 V2.0**：多场地负载均衡、队伍分区固定场地、两轮错位对阵、同组别串行不插队、最小休息间隔
- **报表导出**：资格赛排名表 / 晋级队伍表 / 淘汰赛对阵表 / 按场地检录表 / 组别排程表 / 抽签报名模板，全部为标准 .xlsx
- **赛事大屏**：分屏展示（①资格赛实时排名自动滚动 / ②淘汰赛对阵树 + 冠亚季军），5 秒自动刷新，支持全屏与独立窗口投屏
- **安全与审计**：操作密码（哈希存储）、锁屏/自动锁屏、重置数据需密码、全操作日志留痕（修改前后对比）、已锁定比赛改分需填原因
- **数据本地化**：所有数据保存在浏览器 localStorage，不上传任何服务器；支持 JSON 一键备份/恢复

## 🚀 快速开始

### 方式一：直接打开（推荐现场使用）

1. 用 Chrome / Edge 打开 `index.html`
2. 首次使用请到「赛事设置 → 操作密码」修改默认密码（默认 `admin123`）
3. 按 `操作指南.html` 中的 12 步流程完成赛事（建组 → 导入队伍 → 抽签 → 编排 → 排程 → 录入 → 排名 → 晋级 → 淘汰赛 → 大屏 → 报表）

### 方式二：部署为静态网站（GitHub Pages / 任意静态服务器）

整个系统是纯静态单文件应用，把仓库内容直接放到任意静态服务器即可，无需构建：

- GitHub Pages：仓库 Settings → Pages → 选择 `main` 分支根目录
- Nginx / 任意静态托管：直接拷贝即可

## 🧰 技术栈

| 项目 | 说明 |
|---|---|
| 前端 | 原生 HTML + CSS + JavaScript，无任何外部依赖、无需构建 |
| 架构 | 单文件应用：`XCEM.Algorithm`（纯算法）/ `XCEM.Engine`（业务服务）/ `XCEM.UI`（视图）/ `XCEM.Log`（审计）分层 |
| 存储 | 浏览器 localStorage（数据完全本地化） |
| 导出 | 内置 xlsx 生成器（ZIP 格式，兼容 Excel） |

## 🔐 隐私与数据安全

- 系统**不联网、不上传**任何数据，所有赛事数据仅存储在本机浏览器 localStorage 中
- 建议每天赛程结束后通过「赛事设置 → 导出 JSON 备份」留存数据，并将备份文件保存至 U 盘或网盘
- 更换电脑时使用「从 JSON 恢复」迁移数据
